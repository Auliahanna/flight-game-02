Skylark Run — a tiny original flight game. Take off from a grass strip, thread a course of sky rings over patchwork farmland and a winding river, mind your speed so the Skylark does not stall, then bring her home and land gently on the HOME runway. Three courses of rising difficulty, a lit instrument HUD (speed, altitude, heading, vertical speed, throttle, artificial horizon), stall warnings, wind gusts, and landing grades.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve `game/` with any static HTTP server and open `game/index.html` in a desktop browser. Controls: W/S or ↑/↓ pitch, A/D or ←/→ bank, Shift/Ctrl throttle, Space brake, P pause, R restart. Mouse drag also steers.
